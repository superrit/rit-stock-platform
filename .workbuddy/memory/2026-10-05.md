# 2026-10-05 工作日志

## 外部接口 + 登录记录 + VIP 续期解耦（第三版交付）

### 完成内容
1. **RSA 核心密钥对 + 公钥接口**
   - 生成 RSA-2048 密钥对，私钥以 PKCS8 PEM 的 base64 存 `NUXT_RSA_PRIVATE_KEY`（仅服务端）
   - `server/utils/rsa.ts`：getPublicKeyPem / getPublicKeyInfo / decryptWithPrivateKey（OAEP-SHA256）
   - `GET /api/rsa/public-key`（公开接口，返回公钥），已做加解密 round-trip 验证
2. **策略上报接口**
   - `strategy_reports` 表（hash 主键/唯一索引，upsert 覆盖）
   - `POST /api/strategy/report`：MD5(ts+JSON.stringify(data)+32位盐) 签名校验 + ts 时间窗口防重放 + 500条分片事务批量 upsert
   - 配置：`NUXT_SIGN_SALT`（32位）、`NUXT_REPLAY_WINDOW_MS`（默认300000）
3. **登录记录**
   - `login_records` 表（phone/ip/device/login_at），登录成功后记录，顺带清理 >6个月
   - `GET /api/login-records`（仅管理员，分页）+ `/admin/login-records.vue` 查看页
4. **VIP 续期解耦 + 操作记录**
   - 续期接口改为统一枚举 `duration`：1month/3months/6months/1year（前端不可自由上送时长）
   - `vip_operation_records` 表：操作时间/延长类型/操作人手机/被修改人手机
   - `GET /api/vip-records`（仅管理员，分页）+ `/admin/vip-records.vue` 查看页

### 关键设计
- 签名规则：sign = MD5(ts + JSON.stringify(data) + signSalt)，注意 JSON.stringify 需与服务端反序列化后重新序列化一致（键序一致、无空白）
- ts 防重放兼容 13位毫秒/10位秒（<1e12 视为秒）
- 登录记录时机：full 登录 + 改密后自动登录两处都记录
- IP 取 `getRequestIP(event, {xForwardedFor:true})`，设备取 user-agent
